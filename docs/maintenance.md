# Profile maintenance

GitHub renders the root `README.md` of the public `rucNick/rucNick` repository on
[the profile](https://github.com/rucNick).

- Edit the display name and technology labels in `README.md`.
- Keep the profile in English, with a static layout and no project showcase.
- `assets/frontend.svg`, `backend.svg`, and `cloud.svg` are vendored Skill Icons.
  See `assets/THIRD_PARTY.md` for attribution and the included license.
- `assets/ai.svg` is original, static profile artwork.

All technology icons are served from this repository. No scheduled workflow or
external image service is required.
