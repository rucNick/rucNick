# Third-party artwork

`frontend.svg`, `backend.svg` and `cloud.svg` combine icons from
[tandpfun/skill-icons](https://github.com/tandpfun/skill-icons), pinned at
`7f7e691e71aec64e8354bf697835e009d1ad80f8`.

The source artwork is MIT licensed; the complete notice is in
[`SKILL_ICONS_LICENSE`](./SKILL_ICONS_LICENSE). Brand names and logos belong to
their respective owners. Changes are limited to assembling icon strips and
namespacing SVG IDs. Regenerate with `python3 scripts/build-icons.py` (requires
authenticated GitHub CLI and network access).

`ai.svg` is original, static profile artwork.
